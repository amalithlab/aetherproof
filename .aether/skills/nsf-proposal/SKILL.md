# NSF Proposal Writing Skill

## Structural Requirements
- Every proposal must explicitly address **Intellectual Merit** and **Broader Impacts** in dedicated sections.
- Maintain strict page limits: 15 pages for Project Description (CORE: Small), 20 pages (CORE: Medium).
- Use NSF-approved fonts: Times New Roman 11pt, margins ≥ 1 inch.

## Citation Standards
- All references must include: Author(s), Title, Venue/Journal, Year, DOI or URL.
- Use BibTeX-compatible citation format.
- Minimum 40 references for a competitive SaTC proposal.

## SaTC-Specific Requirements (NSF 25-515)
- Align with at least one SaTC research theme: Trustworthy Computing, Privacy, or Sociotechnical Cybersecurity.
- Include a clear threat model with formal definitions where applicable.
- Budget should include REU supplement opportunity if appropriate.
- Broader Impacts must include education and workforce development components.

## LaTeX Compilation
- Use `\documentclass[11pt]{article}` with `\usepackage{fullpage}`.
- All section labels must match NSF template structure.
- Run `pdflatex` twice to resolve cross-references before submission.
